Méthode

Comment se déroule le projet

  1. Étape 1

    Échange

    Nous définissons ensemble les fonctionnalités prioritaires. Je vous envoie un devis détaillé.

  2. Étape 2

    Maquettes

    Je dessine les écrans clés et les parcours. Vous validez avant le développement.

  3. Étape 3

    Développement

    Je développe par sprints de trois semaines, avec une version à tester à la fin de chacun.

  4. Étape 4

    Publication

    Je publie l'application sur l'App Store et Google Play, puis j'assure le suivi.

Questions fréquentes

Vos questions

Une autre question ? Écrivez-moi directement.

Pourquoi React Native plutôt que deux applications natives ?

Une seule base de code pour iOS et Android réduit le budget et les délais, et les deux versions évoluent en même temps. J'explique tout dans cet article.

Combien de temps faut-il ?

De quelques mois à près d'un an selon les fonctionnalités. Le devis détaille le planning, sprint par sprint.

L'application m'appartient-elle ?

Oui. Une fois le projet réglé, vous recevez le code source et la documentation, et les comptes des stores sont à votre nom.

Parlons de votre projet

Le premier échange est gratuit et sans engagement. Je vous réponds sous 48 h ouvrées.
